Prefix Concatenative

PreForth eliminates the mental hurdle of reverse polish notation (RPN). Write + 1 2 naturally. The statement chunker reverses tokens right-to-left, compiling directly into linear postfix instructions.

O(1) Goto Jumps

Build blazing-fast state machines with zero call-stack overhead. Unconditional and conditional jumps (goto, ?goto, ?!goto) compile to integer index jumps without recursion depth buildup.

Bidirectional C ABI

Call external C libraries, export PreForth words as C ABI symbols, and produce native shared libraries (.so, .dll, .dylib) or compile to WebAssembly with zero glue code.

1. The Golden Rule of Prefix Evaluation

Statements execute top-to-bottom. Within each statement, tokens are compiled in reverse order (right-to-left). In + 2 3, 3 is pushed first, 2 is pushed second, and + pops 2 and 3 to produce 5.

Prefix Arithmetic
+ 2 3 - 10 * 2 3 / 20 + 2 3

2. Non-Commutative Binary Operations

Because statements are reversed, binary operators pop lhs = pop() first and rhs = pop() second. Mathematical order is fully preserved for subtraction, division, and comparisons.

lhs - rhs and comparisons
- 10 3 # lhs=10, rhs=3 -> 7 / 20 4 # lhs=20, rhs=4 -> 5 % 17 5 # 2 < 3 5 # 1 (true) > 10 20 # 0 (false)

3. Dual Stack Manipulation

PreForth provides standard 64-bit Forth stack operations: dup (duplicate TOS), drop (discard TOS), swap (swap top two), and over (copy 2nd element to top).

Stack Primitives
# Push 42, duplicate, then multiply dup 42 *

4. Defining Words & Recursion

Use def <name> ... ; to compile statements into reusable bytecode blocks. Recursive calls invoke the enclosing word naturally.

Factorial Word
def fact if == dup 0 then 1 drop else * fact dec dup end ; fact 5

5. Goto State Machines & Labels

PreForth supports O(1) linear jumps via goto, ?goto (conditional if true), and ?!goto (conditional if false). Ideal for state machines that require constant call stack space.

Collatz 3n+1 Loop
var n var steps def collatz set steps 0 set n loop: ?goto done == @ n 1 set steps inc @ steps ?goto is_even == % @ n 2 0 set n + * 3 @ n 1 goto loop is_even: set n / @ n 2 goto loop done: @ steps ; collatz 27

6. Dictionary Variables & Stores

Declare global 64-bit variables with var <name>. Fetch values using @ <var> and store new values using set <var> <val>.

Variables & Memory
var counter set counter 100 set counter + @ counter 50 @ counter

7. Printing & Strings

Use print or . (dot) to pop and display the top of the stack. String literals support standard C escape sequences (\n, \t, \").

Printing
print "Hello from PreForth!" . 42 . * 7 9

8. C ABI Interoperability & AOT

Dynamically bind external libraries with extern, or compile directly to Position-Independent C99 code and native .so / .dll shared libraries with export and build-shared.

C Export & Linker Directives
# Export hyp_sq as a real C ABI symbol: # int64_t pf_hyp_sq(int64_t a, int64_t b) def hyp_sq + * dup swap * dup ; hyp_sq 3 4
