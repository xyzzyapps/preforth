Learn PreForth in Y Minutes

PreForth is a prefix concatenative systems language. You write natural prefix expressions like + 2 3, which compile down to linear postfix bytecode for $O(1)$ goto jumps and zero-overhead C ABI interoperability.

1. The Golden Rule of Prefix Evaluation

PreForth code executes top-to-bottom. Within each statement, tokens are compiled in reverse order (right-to-left) so prefix expressions turn into linear execution instructions.

In + 2 3, the number 3 is pushed first, 2 is pushed second, and + pops 2 and 3 and adds them to produce 5.

# Basic prefix arithmetic
+ 2 3 - 10 * 2 3 / 20 + 2 3

2. Non-Commutative Binary Operations

Because prefix statements are reversed, binary operators pop lhs = pop() first and rhs = pop() second:

# lhs - rhs and lhs / rhs
- 10 3 # lhs=10, rhs=3 -> 7 / 20 4 # lhs=20, rhs=4 -> 5 % 17 5 # 2 < 3 5 # 1 (true) > 10 20 # 0 (false)

3. Stack Primitives

PreForth provides standard Forth 64-bit data stack primitives:

  • dup : ( a -- a a ) Duplicate Top-of-Stack
  • drop : ( a -- ) Discard Top-of-Stack
  • swap : ( b a -- a b ) Swap top two cells
  • over : ( a b -- a b a ) Copy 2nd element to top
# Stack manipulation & squaring
# Push 42, duplicate, then multiply dup 42 *

4. Defining Words & Recursion

Use def <name> ... ; to compile words into reusable bytecode blocks. Definitions support recursion naturally:

# Recursive factorial
def fact if == dup 0 then 1 drop else * fact dec dup end ; fact 5

5. Goto State Machines & Labels

PreForth features zero-overhead, $O(1)$ bytecode jumps using labels, goto, ?goto, and ?!goto.

Here is the Collatz Conjecture state machine running in $O(1)$ constant call stack space:

# Collatz 3n+1 loop
var n var steps def collatz ! steps 0 ! n loop: ?goto done == @ n 1 ! steps inc @ steps ?goto is_even == % @ n 2 0 ! n + * 3 @ n 1 goto loop is_even: ! n / @ n 2 goto loop done: @ steps ; collatz 27

6. Variables & Memory Slots

Declare global 64-bit dictionary variables with var <name>. Store with ! <var> <val> and fetch with @ <var>:

# Variables and update
var counter ! counter 100 ! counter + @ counter 50 @ counter

7. Printing & C Strings

Use . or print to print values and strings:

# Print outputs
print "Welcome to WebAssembly PreForth!" . 42 . * 7 9
